# Portfolio | Zayan Teixeira Correa

Landing page pessoal com resumo profissional, projetos, habilidades tecnicas e formacao academica.

## Tecnologias

HTML e CSS puro. Nenhuma dependencia. Pronto para GitHub Pages.

## Como publicar

1. Substitua `foto.jpg` por sua foto real (opcional)
2. Atualize os links de GitHub, LinkedIn e e-mail no cabecalho
3. Hospede no GitHub Pages: Settings > Pages > Source: main branch

## Estrutura

```
portfolio/
├── index.html    Pagina completa
├── cv.pdf      Meu CV Ataulizado (opcional)
└── README.md     Este arquivo
```
